# 🪙 Tip Calculator App (TipTime)

A clean and interactive Android app built with **Jetpack Compose** that calculates tips based on bill amount and custom percentages, with an option to round up the tip.

This app is based on the official [Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course) codelab by Google.

## ✨ Features

- **Dynamic Tip Calculation**: Computes the tip in real time as you enter values.
- **Custom Percentages**: Enter any custom tip percentage for your service.
- **Round Up Option**: Easily round up the calculated tip amount using a toggle switch.
- **Material 3 UI**: Clean user interface built entirely with Jetpack Compose components.
- **Accessibility & UX**: Clear input fields, keyboard actions (`Next` / `Done`), and vector icons.
